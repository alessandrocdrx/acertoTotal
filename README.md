# CelsoPix

Controle de cobranças Pix no celular: cadastre clientes, dê baixa com o comprovante e veja quem está em atraso.

- Protótipo navegável: `prototipo/celsopix.html` (publicado em https://claude.ai/artifact/AmxvF5aaQtretFKakGHWLA)
- Testes automatizados: `bash testes/rodar.sh`
- App Android (APK): `android/` (casca Kotlin + WebView que empacota o protótipo)
- Aprendizados, regras e técnicas de usabilidade: `docs/aprendizados.md`
